# ChalkTalk voice-over (edge-tts)

`scripts/chalk-tts.py` (`npm run chalk:tts -- <slug>`) reads `episode.json`, sends each scene's
`say`/`sayLong` to edge-tts with **WordBoundary** events, and writes per format:
- `public/chalk/<slug>/<fmt>/s<NN>.mp3` — one file per scene (NN = index in `episode.scenes`)
- `timing.json` — duration + every word's start/length. Remotion uses it for scene length,
  word-synced captions, and **cue frames** (a stat appears when its number is spoken).

## Voice
`"voice": { "name": "en-US-AndrewNeural", "rateShort": "+10%", "rateLong": "+0%", "pitch": "+0Hz" }`
- Channel default: **en-US-AndrewNeural** (warm, confident). Alternatives: `en-US-ChristopherNeural`
  (authoritative, news), `en-US-BrianNeural` (casual), `en-GB-RyanNeural` (British),
  `en-US-AriaNeural` / `en-US-EmmaNeural` (female). List all: `edge-tts --list-voices | grep en-`.
- Keep one voice per channel — it is the brand.
- Short: `+8%…+12%` rate. Long: `+0%`. Don't go above `+15%`; numbers get mushy.

## Writing for the ear
- Short sentences. Numbers as digits with commas (`1,399`); edge-tts reads them correctly and
  captions show digits.
- Pause comes from punctuation: `"Number seven. Pakistan, 1,399."`
- Mispronounced names: add to `PRONOUNCE` in the script (`{"Türkiye": "Turkey-yeh"}`); captions keep
  the original spelling.

## Regenerate / fix
```bash
npm run chalk:tts -- <slug> --format short     # one format
npm run chalk:tts -- <slug> --only 7           # one scene (others reused from timing.json)
```
- `NoAudioReceived` happens now and then; the script retries 5× with backoff.
- DNS/connection error → the host is blocked. In a cloud session the environment must allow
  `speech.platform.bing.com`; the script uses `$HTTPS_PROXY` and the container CA automatically.
  Elsewhere: run the script on any machine with internet and commit the mp3 + timing.json.

## Mix
- Voice plays at full volume; the music bed (`episode.music`, default 0.2) ducks to 40% while the
  narrator speaks (`DuckedMusic` in `Explainer.tsx`).
- SFX per scene: `chalk-tap` (start), `chalk-write` (rank writes), `eraser` (scene change). Generated by
  `npm run sfx`.
- `render.sh` → `finalize.sh` normalises to −14 LUFS. Check `info.txt` after render.
