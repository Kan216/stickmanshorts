# Storyboard a stickman short

Write the result to `storyboards/<slug>.md` using `docs/STORYBOARD_TEMPLATE.md`.

## 1. Find the metaphor (the whole short hangs on it)
Turn the abstract lesson into a **physical situation a stickman can be in**:

| Abstract | Physical metaphor |
|---|---|
| consistency vs intensity | hanging on a bar / climbing stairs / running laps |
| the past holds you back | chained weight underwater, backpack of rocks |
| fear / overthinking | thought cloud growing, shadows on a wall, a door that won't open |
| opportunity | archery target, door, ladder, falling fruit |
| comparison / envy | two lanes, a glowing orb someone else holds |
| procrastination | couch vs stairs, counter "DAYS WAITING" climbing |
| support / family | split-screen: alone vs with someone |
| ego | figure that grows bigger, then breaks/falls |
| discipline | quiet figure that keeps going after others stop |

Good metaphors are: instantly readable without text, have a **measurable variable** (counter,
height, light level, number of arrows) and a **reversal** (the expected winner loses / the
obstacle becomes the step).

## 2. Choose a format (see docs/STYLE_GUIDE.md §7)
Versus lanes · A/B split · Chapter series · Metaphor object · Counter flip · Compilation.

## 3. Structure (12–25s)
| Phase | Time | Purpose |
|---|---|---|
| Hook | 0–1.5s | Question headline + cast already on screen + motion in frame 0. "WHO STOPS FIRST?" |
| Setup | 1.5–4s | Rules of the game become clear (counters start). |
| Escalation | 4–10s | Characters diverge. A headline per turning point: "{teal:TALENT} GOT BORED." |
| Twist / payoff | 10–13s | The surprising winner, the light, the counter flip. Riser → ding. |
| Punchline | 13s–end | Question to viewer or 2-line maxim (line 2 in gold). Hold ≥ 2s. |

For a **series** (45–65s): N chapters × 6–9s, each with its own colour + label, one shared
"progress object" that fills chapter by chapter, and a final 1-word resolution (e.g. "BOW.").

## 4. Writing rules
- Headlines: ALL CAPS, ≤ 6 words, past tense for verdicts ("EGO BROKE TRYING."), 1 coloured keyword.
- Names of characters ARE the concepts (TALENT, DISCIPLINE, EGO, HABIT, FEAR, THE PAST).
- Counters must change visibly at least every 2s during escalation.
- The ending addresses the viewer ("YOU") or states a maxim. No hashtags/emoji on screen.
- Every beat lists its SFX.

## 5. Output
The filled template + a one-line **title** and **caption** for posting, e.g.
- Title: `Who stops first? 💪 #discipline #motivation #shorts`
- 3 alternative hooks (A/B testing).

## Idea generator
When the user asks for ideas, give 5–10 rows: `Hook headline | Metaphor | Format | Punchline`.
